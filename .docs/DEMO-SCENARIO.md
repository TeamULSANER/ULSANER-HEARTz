# HEARTz 데모 영상 시나리오·대본

운전자 '장클로드' 한 사람의 하루로 HEARTz를 보여 준다. 장클로드는 이촌한강공원을 지나며 김피티가 남긴 목소리 사연을 듣는다. 그 자리에서 Gleo에게 말해 자기 사연을 남기고, 국립한글박물관에서는 상도동메시가 남긴 변조 목소리(TTS) 사연을 지나친다. 주차한 뒤에는 지나온 사연을 다시 듣고, 장소를 직접 골라 기억 하나를 남긴 다음 내 사연함에서 확인한다. 화면은 Pleos Connect 에뮬레이터의 내비 + HEARTz 분할 화면이다.

- 기준: 2026-11-13 앱(debug), 데이터 연결 **기기 안**. 이 흐름은 2026-11-13 12:20–12:23에 에뮬레이터에서 리허설했다. Gleo 음성 명령만 실제 Gleo 대신 모의 호출로 확인했다.
- 대사 대본: [DEMO-RECORDING-SCRIPT.md](DEMO-RECORDING-SCRIPT.md). 위치·기어 명령: [DRIVING-TEST.md](DRIVING-TEST.md).
- 아래 `geo X Y`는 `adb -s emulator-5554 emu geo fix X Y`(경도 위도)의 줄임이고, `기어 D/P`는 `curl -X PUT "http://127.0.0.1:8088/vehicle/gear?gear=Drive|Park"`의 줄임이다.

좌표는 앱의 랜드마크 목록으로 거리를 계산해 골랐다. 이촌한강공원 안쪽에서는 김피티 사연만, 한글박물관 안쪽에서는 상도동메시 사연만 도착한다. 그 반경 안의 국립중앙박물관 사연은 검수 대기라 오지 않는다. 김피티의 잠수교 사연은 두 지점 모두에서 1.2 km 넘게 떨어져 있다.

## 장면별 대본

표기: **[내레이션]** 편집에서 입히는 목소리 · **[조작]** 촬영 담당 · **[앱]** 앱이 실제로 말하는 문장(자막으로 보여 줌) · **[장클로드]** 연기자가 마이크에 하는 말. 앱이 말하는 동안에는 내레이션을 넣지 않는다.

### 1. HEARTz 실행

- [조작] 분할 화면에서 HEARTz가 열린 상태(장클로드, 기어 P)로 녹화를 시작한다.
- [내레이션] "매일 지나는 길에도 누군가의 기억이 있습니다. HEARTz는 그 길에 남겨진 사연을, 지금 그 길을 지나는 사람에게 들려줍니다."

### 2. 출발

- [조작] 기어 D → `geo 126.9450 37.5290`. HEARTz가 주행 화면으로 바뀐다.

### 3. 김피티의 목소리 사연

- [조작] `geo 126.9650 37.5175`.
- [앱] "이촌한강공원에서 사연이 도착했어요. 읽어드릴게요."
- [재생] 김피티의 녹음(13초).
- [앱] "이번 사연은 어떠셨어요? 공감 하트를 남길까요?"
- [장클로드] (선택) "응, 남겨줘." → [앱] "사연자님께 마음이 전달되었어요." 답하지 않으면 약 10초 뒤 "다음에는 따뜻한 마음 하나 남겨보아요."가 나온다.
- 공감 질문과 그 대답이 끝날 때까지 기다린 뒤 4로 넘어간다.

### 4. Gleo로 지나면서 남기기

- [내레이션, 3과 4 사이] "이번에는 내가 이 길의 이야기를 남길 차례입니다. 운전 중이니 손 대신 목소리로요."
- [장클로드 → Gleo] Gleo를 부른 뒤 "하츠에서 지금 지나는 곳에 사연 남길래."
- [Gleo] 수락 대답. HEARTz는 Gleo가 말을 마칠 때까지 기다렸다가 시작한다.
- [앱] "사연을 말해주세요." 화면: "● 녹음 중", 0:00 / 1:00, 오른쪽 위 "이촌한강공원".
- [장클로드] 대본 L1(약 15초). 중간에 3초 넘게 쉬지 않는다. 다 말하고 조용히 있으면 3초 뒤 저절로 멈추고 바로 질문 화면으로 넘어간다.
- [앱] "이 사연을 전달할까요? 다시 녹음하려면 '다시'라고 말해 주세요." → [장클로드] "응, 보내줘."
- [앱] "원하시면 변조 목소리로 사연을 전달할까요?" → [장클로드] "아니, 내 목소리로."
- [앱] "사연을 보냈어요. 검수 후 공개돼요." 화면 "검수에 보냈어요".

### 5. 상도동메시의 TTS 사연

- [조작] `geo 126.9850 37.5240`.
- [앱] "국립한글박물관에서 사연이 도착했어요. 읽어드릴게요."
- [TTS] "한글박물관에서 아이가 처음으로 자기 이름을 써 봤어요. 삐뚤빼뚤한 글씨를 보고 둘이 한참 웃었는데, 그 종이가 아직도 냉장고에 붙어 있어요."
- [내레이션, 끝난 뒤] "목소리를 드러내고 싶지 않은 사람은 변조 목소리로 남길 수 있습니다. 듣는 사람에게는 안내 목소리로 읽어 줍니다."
- 공감 질문에는 답하지 않고 지나간다(약 10초 뒤 저절로 닫힌다).

### 6. 지나침

- [조작] `geo 126.9900 37.5330` → 기어 P. HEARTz가 주차 화면 '지금 이 길'로 바뀐다.

### 7. 지나온 사연

- [조작] 지금 이 길의 **지나온 사연** → 목록 맨 위 "용산구 국립한글박물관 · 상도동메시 · 방금 들음" → 상세 → **듣기**(TTS로 다시 읽음, 3–4초만 보여 주고 다음으로).
- [내레이션] "운전 중에 흘려들은 사연도, 차를 세운 뒤 지나온 사연에서 다시 들을 수 있습니다."
- 주의: 주차 화면의 '지금 이 길'에는 사연 카드가 직접 뜨지 않는다. **지나온 사연** 버튼으로 들어가야 한다.

### 8. 주차 중 남기기

- [내레이션] "주차한 상태에서는 직접 장소를 골라, 문득 떠오른 기억을 그 장소에 깃들일 수 있습니다."
- [조작] **남기기** → 검색창에 "남산" → **남산서울타워** → 마이크 버튼 → 대본 P1 → 마이크 버튼으로 멈춤 → (선택) 미리 듣기 → **내 목소리** → **보내기**.
- [화면] "검수에 보냈어요".

### 9. 내 사연함

- [조작] **내 사연함 보기**.
- [화면] "용산구 남산서울타워 · 검수 중", "용산구 이촌한강공원 · 검수 중".
- [내레이션] "남긴 사연은 운영자의 검수를 거쳐, 그 길을 지나는 다음 사람에게 닿습니다."

### 10. 엔딩

- [화면] HEARTz 로고.
- [내레이션] "지나온 길 위의 한마디가, 다음 사람의 하루에 닿습니다. HEARTz."

## 촬영 전 준비 (매 테이크마다)

```bash
cd ~/pleos_app && source .tools/env.sh
s=emulator-5554
xdg-open http://127.0.0.1:8088/                    # Virtual Console 탭(닫혀 있으면 기어 명령이 503)
curl -X PUT "http://127.0.0.1:8088/vehicle/gear?gear=Park"
adb -s $s emu geo fix 126.9450 37.5290             # 바깥에서 시작
adb -s $s shell am broadcast --user 10 -n ai.heartz.app/.debug.DebugCommandReceiver -a ai.heartz.app.debug.CLEAR_LISTENS
adb -s $s shell am force-stop --user 10 ai.heartz.app     # 앱이 기억하는 '이번 주행에서 띄운 사연'도 비운다
adb -s $s shell am start --user 10 -n ai.heartz.app/.MainActivity
adb -s $s emu avd hostmicon                        # 장클로드 대사·Gleo가 PC 마이크를 듣게(끝나면 hostmicoff)
```

1. **받은 기록 + 앱 재시작:** 같은 사연은 같은 계정에 두 번 오지 않는다. 받은 기록(`CLEAR_LISTENS`)을 지워도 앱이 켜져 있는 동안은 '이번 주행에서 띄운 사연'을 따로 기억한다. 그래서 **앱도 다시 켠다**(리허설에서 확인). `CLEAR_LISTENS`는 장클로드로 로그인한 상태에서 실행한다.
2. **하트:** `CLEAR_LISTENS`는 하트를 지우지 않는다. 지금 장클로드는 김피티 사연에 하트를 남긴 상태다(12:05 리허설). 7장면 목록에 하트가 보이지 않게 하려면 지나온 사연 → 김피티 사연 → **공감**을 다시 눌러 취소한다.
3. **리허설 사연 지우기:** 리허설로 남긴 장클로드 사연은 내 사연함에서 삭제한다. 그래야 9장면에 이번 테이크의 두 개만 보인다.
4. **녹화:** Kazam Speakers = "Monitor of HEARTz_녹화_믹스", Sound from speakers만 체크. 헤드셋이나 이어폰을 쓴다. 스피커 소리가 마이크로 들어가면 앱이 자기 질문을 답으로 들을 수 있다.
5. **Gleo:** 실제 음성으로 녹음 시작(`START_STORY_RECORDING`)을 확인한 적은 없다. 앱 쪽은 모의 호출로 확인했다(12:21 리허설: Gleo 대답을 기다린 뒤 녹음 → 보냄). **본 촬영 전에 실제 Gleo로 한 번 해 본다.** Gleo가 못 알아들으면 화면의 **지나면서 남기기** 버튼을 누른다. 그 뒤 흐름은 같다.

- 3장면에서 하트를 남길지(남기면 7장면 목록에 하트가 보인다).
